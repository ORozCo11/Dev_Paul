# Historical VMS documentation

This folder preserves the earlier reviews, planning records and superseded exports moved out of `VMS Docs` on 24 October 2026. Use [the current document index](../../../VMS%20Docs/README.md) for the maintained references and latest example presentation.

These documents remain useful as dated evidence, not as statements of current permissions, interface behavior or acceptance. Earlier reports describing resolved findings do not close the six findings in the [24 October audit](../../../VMS%20Docs/System-Audit-2026-10-24.md).

Some historical reports link to log files that are absent from this checkout (133 existing link references). Those evidence files were already missing before this cleanup; their links retain the original intended location.

The archive includes:

- Earlier system, regression and Super Admin reviews and fix reports.
- Role-alignment analysis and the earlier improvement plan.
- UI change and branding history.
- Geography setup, reference provenance and boundary-accuracy review records.
- Superseded defense presentations and the earlier generated requirements DOCX.

Geographic evidence remains relevant when investigating reference coverage or unresolved boundary accuracy. Its archival location does not mean those limitations are fixed. See [the geography audit](../../geography-audit-2026-10-22.md) and [boundary data governance](../../barangay-boundary-data-governance.md) for related guidance.
